# Logitech Plugin Studio

Windows-Studio und Python-Anbindung für Logitech-Actions-SDK-Plugins.

Dieser Branch (`main`) enthält je veröffentlichter Release-Version genau einen Commit.
Die laufende Entwicklung findet auf dem jeweiligen Release-Branch (`release/<Version>`) statt,
einzelne Features auf `feat/<Name>`-Branches darunter.

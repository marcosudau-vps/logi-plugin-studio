# P0-ADR-006 – Views und Laufzeit-Overrides

- **Status:** `ACCEPTED` / `BASELINE` – 30.10.2026 (ausdrückliche Nutzerfreigabe)
- **Herkunft:** P0-Architekturreview v0.4, in der Gesamtfassung v0.5 übernommen
- **Geltung:** Die nachfolgende Empfehlung ist als Architekturentscheidung übernommen; dadurch wird weder das vollständige Projekt-JSON-Schema noch die Runtime oder der Logitech-Adapter freigegeben.

**Empfehlung:** View ist logische Collection von Placements, nicht identisch mit den neun physischen Slots. Ein Placement referenziert eine ComponentInstance, optional eine Presentation und eine logische Position. Viele Placements dürfen auf dieselbe Komponente zeigen; in einer statischen View wird eine Position nur einmal belegt. Änderungen während der Laufzeit werden als versionierte Runtime-Overrides verwaltet und verändern nicht implizit das Projekt. Atomare Override-Operationen sind erst Gegenstand der P2-Runtime.

**Alternative:** Ordnerliste ist festes Array im C#-Plugin. **Nachteil:** Wiederholung des bereits verworfenen 4/8-Demo-Modells.
